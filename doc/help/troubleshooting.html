Troubleshooting

First-launch issues

"Unable to connect to server" right after Sign In

The most common cause: the Base URL field on the Login dialog points at a server that isn't running, isn't reachable from your network, or requires VPN. Verify: 

>> webread('http://YOUR-QTAU-HOST:5715/health')

If that errors, the workbench cannot reach the server either. Check DNS, firewall, VPN, and that the FastAPI server is actually running.

Login succeeds but Dashboard shows "No data"

Your account may not have any projects yet. Open Projects, click New Project, then return to the Dashboard.

QTAUWorkbenchLauncher: "Undefined function or variable"

The install action did not add the toolbox directory to your MATLAB path. Reinstall the .mltbx, or add the directories manually: 

>> addpath(genpath(fullfile(matlabroot,'toolbox','QTAU Connector Workbench','src')))

Runtime issues

Jobs screen never refreshes

The Jobs screen auto-refreshes every 5 seconds via a MATLAB timer. If your session has many stale timers, MATLAB may throttle them. Run: 

>> delete(timerfindall)

Then re-navigate to the Jobs screen.

QMC popup hangs at "Queued (0%)"

The QMC job was accepted by the backend but the IBM Runtime queue is long. The 3-second poll loop will eventually update. To verify a job is alive, in another MATLAB session: 

>> webread('http://YOUR-QTAU-HOST:5715/api/qae/jobs/JOB_ID')

Circuit upload returns 404

Your Base URL likely has a trailing slash (e.g. http://qtau.example.com:5715/). The HTTP client trims trailing slashes in newer versions; if you see this on an older install, edit resources/app.properties and remove the trailing slash.

Diagnostics

Inspect the structured log

All HTTP requests, service-layer errors, and screen lifecycle events are logged via the Logger class to the MATLAB Command Window. Set verbose logging: 

>> Logger.setLevel('DEBUG');

Reload config without restarting

After editing resources/app.properties or resources/labels.properties: 

>> AppConfig.reload(); Labels.reload();

Reporting bugs

File issues at github.com/sqkcloud/sqk-qtau-matlab/issues with a minimal reproducer plus the Command Window output captured after setting Logger.setLevel('DEBUG').
