Getting Started

This page is a short reference. For the full walkthrough with embedded screenshots, open the bundled Live Script: 

>> open(fullfile(matlabroot,'toolbox','QTAU Connector Workbench','doc','GettingStarted.mlx'))

Or from Add-Ons » Manage Add-Ons » QTAU Connector Workbench » Options » Getting Started.

Prerequisites

  • MATLAB R2025b or later.
  • A reachable QTAU FastAPI server. The toolbox is the client only.
  • Login credentials for that server.

Step 1 - Launch

>> QTAUWorkbenchLauncher

The main window appears. The Login dialog opens on top.

Step 2 - Set the server URL

The Base URL field is blank by default in the shipped toolbox. Type your server URL (e.g. https://qtau.example.com:5715). If you leave it blank, the app falls back to http://localhost:5715.

The Base URL is saved in your local resources/app.properties after a successful login. To change it later, open the Settings screen or edit that file directly.

Step 3 - Sign in and tour

  1. Enter username + password, click Sign In.
  2. You land on the Dashboard.
  3. Open a project from the Projects sidebar entry.
  4. Try the Composer » pick a template (Bell state, GHZ, QFT).
  5. Click Save to upload the circuit, then Analysis to inspect features.
  6. Open the QMC popup from Analysis » Run QMC for a Monte Carlo sweep.
