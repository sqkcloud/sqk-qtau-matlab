Screen Catalog

The workbench has 21 screens (20 visible in the sidebar plus Upload, which is reachable from the Composer toolbar and Circuits toolbar but hidden from the sidebar).

Core workflow screens

ScreenPurpose
DashboardDefault landing post-login. KPI strip, workflow stepper, Run Readiness, Backend Health, Job Submissions trend, merged activity feed, 30s silent auto-refresh.
ProjectsLogin, project picker, recent projects. (Routing key is still 'Welcome' for back-compat.)
CircuitsBrowse, search, manage project circuits. Toolbar exposes Composer and Upload entry-points.
ComposerIn-app circuit authoring with template gallery, gate palette, OpenQASM bidirectional mirror, Inspect footer, multi-target code export, reproducibility bundle.
NotesWorking notes and operator memos. Per-project markdown notes with checklists.
AnalysisCircuit feature extraction, QTAUBench similarity, Quantum Monte Carlo popup.
Detailed AnalysisHeatmaps, drift, qubit metrics, cross-run comparisons.

Execution-planning screens

ScreenPurpose
BackendsBackend explorer with primary/backup selection and telemetry tabs (Overview / Per-Qubit / History / Topology).
BenchmarkExecution parameters, mitigation strategy, cost.
Benchmark DashboardBenchmark configuration summary and recommendations.
Circuit CuttingCircuit cutting + distributed reconstruction.
PredictionPredicted fidelity, distribution, error budget.
Mitigation CompareSide-by-side cost / shot-multiplier / runtime / IQP-cost cards for None / Minimal / Standard / Aggressive mitigation strategies.
Resource EstimatorFault-tolerant overhead planner. Surface-code distance, T-state budget, T-factory count, total runtime.
Run PlannerCost-aware run optimisation. Picks the cheapest (backend x mitigation x shots) configuration that meets a target fidelity, via a Pareto frontier.

Execution and review screens

ResultsMeasured vs predicted vs ideal result analysis.
ReportsReport generation and viewing (PDF, HTML).
SettingsAccount settings, defaults, storage, notifications.
