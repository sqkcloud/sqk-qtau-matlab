MATLAB Integration

The Composer round-trips circuits, data, and simulation through MATLAB's own quantum tooling, so your work stays inside MATLAB end to end. Every path on this page works offline — no QTAU server login is required.

The interop layer uses the MATLAB Support Package for Quantum Computing (quantumCircuit, simulate, gate constructors). When the add-on is not installed, these features degrade gracefully: the import/simulate buttons report that the package is missing, and the rest of the Composer still works. Importing MATLAB data and pasting OpenQASM need no add-on at all.

Import a circuit created in MATLAB

Build a circuit with the Support Package, then bring it into the Composer two ways:

Direct object import

>> c = quantumCircuit([hGate(1); cxGate(1,2)], 2);   % a Bell circuit

In the Composer toolbar click Import MATLAB, pick c from the workspace list, and the canvas renders it. MATLAB's 1-based qubit indices are shifted to the app's 0-based convention automatically.

Via generateQASM()

>> qasm = generateQASM(c);

Paste the result into the Composer's OpenQASM mirror and it commits to the canvas. The mirror accepts both OpenQASM 2.0 and the OpenQASM 3.0 that generateQASM() emits (the qubit[n] / bit[n] declarations and the whole-register c = measure q; form are all understood).

Simulate with MATLAB's built-in engine

The Composer's Inspect footer runs a local statevector simulator. When the Support Package is present, it also runs MATLAB's native simulate() on the same circuit and flashes a parity check — "MATLAB simulate() matches local simulator" — so you can trust the in-app preview against MATLAB's authoritative engine.

Export back to MATLAB

From the Composer toolbar choose Export. The dialog leads with the workflow-native targets:

  • MATLAB (quantumCircuit) — a runnable script that rebuilds the circuit as a quantumCircuit object (default).
  • OpenQASM 2.0 / 3.0 — standard interchange.
  • Advanced — Qiskit / Cirq / Braket Python, for collaboration or downstream execution on those platform SDKs.

To keep working in MATLAB without a file round-trip, click Push to workspace in the same dialog: it writes a live quantumCircuit to the base workspace (as qtau_circuit) that you can simulate, transpile, or analyze with the rest of your MATLAB code.

Import MATLAB data as a parametric circuit

Turn numeric MATLAB data into a circuit. Put a vector (or a numeric table) in the workspace: 

>> theta = linspace(0, pi, 5);

Click Import data in the Composer toolbar and pick theta. The values become the rotation angles of a hardware-efficient ansatz — one Ry per value (capped at 16 qubits) plus a linear CX entangling chain. This is the bridge from MATLAB data analysis into a runnable circuit.

Work offline

The Composer is fully usable without a backend login. From the Projects screen click Explore offline to jump straight in. Building, importing, simulating, and exporting all run locally; only the server-backed screens (Jobs, Backends, Reports, …) require authentication.

A focused interface

The sidebar defaults to the core workflow — build → simulate → analyse → run. Specialist surfaces (Circuit Cutting, Mitigation Compare, Resource Estimator, QEC) are tucked behind the Show advanced toggle at the bottom of the sidebar. Nothing is removed; click the toggle to reveal everything.
