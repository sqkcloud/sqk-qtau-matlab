QTAU Connector Workbench

A professional MATLAB R2025b+ desktop client for managing quantum-circuit experiments through the QTAU FastAPI backend.

v1.1.0 Apache 2.0 Windows / macOS / Linux

What it does

  • 20+ workflow screens for circuit upload, in-app composition, analysis, backend exploration, benchmark planning, fidelity prediction, error mitigation, cost-aware run planning, job monitoring, results review, reports, QEC simulation, and 3D visualization.
  • A built-in Quantum Monte Carlo simulator popup with asynchronous IBM Runtime job execution, zero-noise extrapolation, vector-chart PDF reports, and IBM execution-log download.
  • A reproducibility-bundle exporter that packages a circuit as QASM plus Qiskit/Cirq/Braket Python equivalents with a SHA-256-stamped manifest.
  • A pure-MATLAB QEC simulation engine (no backend needed) for the bit-flip, phase-flip, Shor-9, Steane-7, perfect-5, and surface codes.

What it is not

The workbench is a client only — your data lives on whichever QTAU FastAPI server you connect to. The server is a separate open-source project; see the GitHub repository for backend setup notes.

Quick start

>> QTAUWorkbenchLauncher

Sets the path, opens the main window, and pops the Login dialog. Fill in your QTAU server base URL (the field starts blank), username, and password. See Getting Started for a detailed walkthrough.
